# Watermeter add-ons

[![Add this repository to your Home Assistant.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Feriktack%2Fwatermeter-addon)

Click the button, then **Install** and **Start** on *Watermeter*. Home Assistant builds it itself, which takes a few minutes.

This repository only holds the add-on's published files (and the ESPHome package for the camera); there is nothing to work on here.
